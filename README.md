# FreeMatrix Git Practice
### A practical, zero-knowledge guide to Git and GitHub for everyone.

> Created with 💖 by **FreeMatrix Studios** and **[@kuraigu](https://github.com/kuraigu)**

Welcome to **FreeMatrix Git Practice**.

If you have never opened a terminal, never touched version control, or always felt like Git was intimidating, this hands-on workshop was built for you.

Git is not just for software developers. Designers use it to track design systems, writers use it for books and documentation, researchers use it for experiments, and team members everywhere use it to collaborate without ever overwriting each other's work.

In this self-paced walkthrough, you will learn the mental model of version control, install Git, fork your own cloud copy, clone it to your laptop, create an isolated branch, protect secrets with `.gitignore`, practice power commands, and submit a formal **Pull Request** on GitHub.

## The Review Guarantee

> [!IMPORTANT]
> When you reach Phase 8, **kuraigu will review your pull request.** If nothing is wrong, it will be merged into the project. If any small adjustments are needed, kuraigu will leave a friendly comment directly on your pull request.
