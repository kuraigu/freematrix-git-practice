Welcome! This directory is your personal sandbox.

## Why Does Everyone Get Their Own Folder?
When multiple people contribute to the same project at once, editing the exact same file creates **merge conflicts**. By giving everyone their own folder (`community/<your-username>/`), you can build, explore, and submit a Pull Request cleanly without colliding with anyone else's work.

---

## How to Set Up Your Space

1. **Duplicate the template folder** and rename it to your GitHub username (or first name):
   ```bash
   # On macOS / Linux / Git Bash:
   cp -r community/_template community/your-username

   # On Windows PowerShell:
   Copy-Item -Recurse community/_template community/your-username
   ```

2. Open `community/your-username/profile.md` in your text editor (VS Code, Cursor, Notepad, etc.).
3. Fill in your details. Tell the community who you are, what you like working on, and what you are currently learning.
4. Continue with the workshop instructions in [`README.md`](file:///A:/Development/GitPractice/README.md)!
